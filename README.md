## 📌 وش هذا؟

مجموعة **قواعد جاهزة** تركّبها في Claude أو ChatGPT أو أي أداة برمجة بالذكاء الاصطناعي.

بعد التركيب، أي كود تطلبه منه بيمشي تلقائياً على:

1. **قواعد البرمجة الاحترافية**: كود مرتب وواضح وكامل، معه اختبارات، ويلتزم بأسلوب مشروعك.
2. **قواعد الأمن**: يحمي من الاختراقات والثغرات المعروفة، ويحافظ على بيانات المستخدمين وكلمات المرور.

ما تحتاج تذكّره بالقواعد في كل مرة، هو يطبقها من نفسه.

## ✨ وش الفرق اللي بتلاحظه؟

| بدون القواعد | مع القواعد |
|---|---|
| يعطيك كود ناقص أو فيه "كمّل الباقي بنفسك" | يعطيك كود كامل جاهز للتشغيل |
| ما يكتب اختبارات | يكتب اختبارات مع كل كود |
| يقول "الكود شغّال" وهو ما جربه | يقول لك بصراحة جرّبه أو لا، ويعطيك طريقة التجربة |
| يخترع مكتبات ودوال غير موجودة | ممنوع يخترع، وإذا ما هو متأكد يقول لك |
| يحط كلمات السر والمفاتيح داخل الكود | يحطها في مكان آمن بعيد عن الكود |
| يخلي أي مستخدم يشوف بيانات غيره | يتأكد إن كل مستخدم يشوف بياناته هو بس |
| ينسى حماية الموقع من الاختراقات المعروفة | يطبّق الحماية تلقائياً |
| يرد بشكل عشوائي | رد مرتب: وش سوّى، الكود، كيف تجربه، والملاحظات |

## 🚀 طريقة التركيب

كل الملفات الجاهزة في مجلد [`dist/`](dist/). اختر المنصة اللي تستخدمها:

### Claude

1. حمّل الملفات من مجلد [`dist/skill-zips/`](dist/skill-zips/)
2. افتح **Settings** ← **Capabilities** ← **Skills** ← **Upload skill**
3. ارفع الملفات واحد واحد، وابدأ بملف `eng-core-standards.zip`

### ChatGPT

**إذا عندك ميزة Skills:** ارفع نفس الملفات من Skills ← Create ← Upload.

**إذا ما عندك:** سوّ **Custom GPT**:
1. Create GPT ← Configure
2. انسخ محتوى ملف [`INSTRUCTIONS.txt`](dist/chat-projects/INSTRUCTIONS.txt) وحطه في خانة **Instructions**
3. ارفع الأربع ملفات اللي في مجلد [`knowledge`](dist/chat-projects/knowledge/) في خانة **Knowledge**

**تبيها في كل محادثاتك؟** انسخ ملف [`SHORT_INSTRUCTIONS.txt`](dist/single-file/SHORT_INSTRUCTIONS.txt) وحطه في Settings ← Personalization ← Custom instructions.

### أي ذكاء اصطناعي ثاني

ارفق ملف [`ALL_SKILLS.md`](dist/single-file/ALL_SKILLS.md) في المحادثة واكتب: **"التزم بهذي القواعد"**.

### أدوات البرمجة (Claude Code، Cursor، Copilot، Codex، Gemini CLI)

انسخ محتوى المجلد الخاص بأداتك من `dist/` وحطه في مجلد مشروعك:

| الأداة | المجلد |
|---|---|
| Claude Code | [`dist/claude-code/`](dist/claude-code/) |
| Cursor | [`dist/cursor/`](dist/cursor/) |
| GitHub Copilot | [`dist/copilot/`](dist/copilot/) |
| OpenAI Codex | [`dist/codex-agents/`](dist/codex-agents/) |
| Gemini CLI | [`dist/gemini-cli/`](dist/gemini-cli/) |

### What is this?

A ready-made set of **26 rule files (skills)** for AI assistants. Install once, and every time you code with Claude, ChatGPT, Cursor, Copilot, Codex or Gemini, the AI automatically follows:

1. **Professional programming rules**: clean, complete, tested code that matches your project.
2. **Security rules**: protection against common vulnerabilities, safe handling of passwords and user data.

### What's included

- **1 core rule set (always on):** how to understand, plan, build, verify and report honestly.
- **14 programming skills:** code quality, architecture, testing, code review, debugging, performance, APIs, databases, frontend (incl. Arabic/RTL and accessibility), monitoring, Git, documentation, refactoring, deployment.
- **11 security skills:** login, permissions, API security, frontend security, server security, data protection, audit logs, security review, risk analysis, safe dependencies, AI app security.

### Install

All ready-made files are in [`dist/`](dist/) — see [`dist/README.md`](dist/README.md).

| Platform | How |
|---|---|
| Claude | Settings → Capabilities → Skills → upload each zip from `dist/skill-zips/` |
| ChatGPT with Skills | Skills → Create → Upload — same zips |
| Custom GPT | Paste `dist/chat-projects/INSTRUCTIONS.txt` into Instructions, upload `knowledge/` files |
| Any chat | Attach `dist/single-file/ALL_SKILLS.md` and say "follow these rules" |
| Coding tools | Copy the matching folder from `dist/` into your project |

### Quick check

Ask: *"Build me a login page."* With the rules active, the AI hashes passwords, limits repeated login attempts, writes tests, and tells you honestly whether it ran them.

### Develop

```bash
python tools/check_framework.py   # validate skills
python tools/build_dist.py        # rebuild dist/ for all platforms
```

Rules improve AI output a lot but don't replace human review and real testing.
